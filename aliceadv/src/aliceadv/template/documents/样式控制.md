# 样式控制（theme.json 配置手册）

本文档说明 `theme.json` 暴露的每一个配置项（字段、类型、默认值、作用、限制），以及首页按钮的显示/隐藏机制、自定义主菜单热区的对齐方法。

剧本指令（段/指令/字段）另见 `剧本格式说明.md`；引擎总体设计与页面清单另见 `定义.md`。

## 1. 基本约定

`theme.json` 是用户对引擎的**唯一配置入口**。引擎模板（`core/`）不写死任何游戏默认内容，所有样式、界面文本、页面布局、按钮可见性都来自本文件。

| 约定 | 说明 |
|---|---|
| 修改后必须重建 | 改完 `theme.json` 后运行 `aliceadv build <工程目录>`，产物输出到 `<工程>/dist/web/`。未重建不会生效。 |
| 相对值（0~1） | 尺寸/位置类字段若为 0~1 的数字，表示相对于**设计画布**的比例（设计画布由 `screen.designWidth/designHeight` 决定，默认 1920×1080）。构建与运行时都翻译为百分比。 |
| 字符串值 | 若写字符串（如 `"3.4em"`、`"60px"`、`"cover"`），原样透传，不翻译。 |
| 资源路径 | JSON 内写工程根相对路径（如 `gui/main_menu.png`、`images/bg/roof.png`）。CSS 内同理写根相对路径，由编译器在构建期按文件深度自动补 `../` 前缀（幂等）。 |
| `_comment` 键 | 任何对象里的 `_comment` 字段仅作说明，构建时忽略，可自由添加。 |

## 2. 顶层字段

### 2.1 screen

定义游戏画布的基础显示参数。

| 字段 | 类型 | 必填 | 说明 | 默认值 |
|---|---|---|---|---|
| `aspect` | string | 否 | 画布宽高比，格式 `"16:9"` | `"16:9"` |
| `designWidth` | number | 否 | 设计画布宽（像素），所有内部尺寸以此为基准等比例缩放 | `1920` |
| `designHeight` | number | 否 | 设计画布高（像素） | `1080` |
| `overflowColor` | string | 否 | 画布之外溢出区域的填充色（CSS 颜色） | `"#0d0d10"` |

`designWidth/designHeight` 同时决定自定义热区坐标 `left/top/width/height` 的归一化基准。主菜单背景图建议按此分辨率制作（如 1920×1080）。

### 2.2 fonts

配置四类文字的字体。四类角色：

| 角色 | 用途 |
|---|---|
| `text` | 对话 / 旁白正文 |
| `interface` | 界面文字（菜单、按钮、提示） |
| `title` | 标题类文字（主菜单标题、页面标题） |
| `system` | 系统文字（跳过提示、错误信息），一般用系统字体栈 |

每个角色有两种写法：

写法一，字符串（系统 / Web 字体栈）：

```json
{
  "fonts": {
    "text": "\"PingFang SC\", \"Microsoft YaHei\", sans-serif",
    "system": "system-ui, -apple-system, \"PingFang SC\", sans-serif"
  }
}
```

写法二，对象（自定义字体文件）：

```json
{
  "fonts": {
    "text": {
      "family": "SourceHanSansLite",
      "src": "fonts/SourceHanSansLite.ttf",
      "fallbacks": "\"PingFang SC\", \"Microsoft YaHei\", sans-serif"
    }
  }
}
```

| 字段（对象写法） | 类型 | 必填 | 说明 | 默认值 |
|---|---|---|---|---|
| `family` | string | 是 | `@font-face` 字体族名 | — |
| `src` | string | 是 | 字体文件路径（工程根相对） | — |
| `fallbacks` | string | 否 | 兜底字体栈，加载失败时降级 | — |

自定义字体文件放在工程 `fonts/` 下，构建时复制到 `dist/web/fonts/` 并生成 `@font-face`。同一 `(family, src)` 自动去重。

### 2.3 colors

颜色变量，供 CSS 变量 `--color-<key>` 使用。键名如下，全部可选，缺省使用引擎内置值。

| 键 | 用途 |
|---|---|
| `accent` | 主强调色（标题、链接、选中） |
| `accentDeep` | 深一档的强调色 |
| `idle` | 文字 / 按钮空闲色 |
| `idleSmall` | 次要空闲文字 |
| `hover` | 悬停色 |
| `selected` | 选中态文字色 |
| `insensitive` | 禁用 / 失效态文字色 |
| `text` | 正文文字色 |
| `interface` | 界面文字色 |
| `paper` | 纸感面板底色 |
| `paperDeep` | 深一档纸色 |
| `muted` | 弱化的强调色（如翻页器） |
| `hoverMuted` | 弱化的悬停色 |

示例：

```json
{
  "colors": {
    "accent": "#3B5998",
    "text": "#402000",
    "paper": "#FAF8F0"
  }
}
```

### 2.12 layout

布局自由度，全部为相对值（0~1）或字符串。

| 子对象 | 字段 | 说明 | 默认 |
|---|---|---|---|
| `dialogue` | `left` `bottom` `width` `height` | 文本框位置与尺寸（相对画布） | `0.05 / 0.05 / 0.90 / 0.28` |
| `dialogue` | `padX` | 文本框左右内边距（字符串，如 `"3.4em"`）；`padLeft`/`padRight` 缺省时回落此值 | `"3.4em"` |
| `dialogue` | `padLeft` `padRight` | 文本框左右内边距独立控制；省略则等于 `padX`（可单独调左/右以贴合背景图） | 同 `padX` |
| `dialogue` | `padY` | 内边距回落值；`padTop`/`padBottom` 缺省时回落此值 | `"2.4em"` |
| `dialogue` | `padTop` `padBottom` | 正文上下留白，缺省回落 `padY` | 同 `padY` |
| `dialogue` | `justify` | 文本框内垂直对齐：`"flex-start"` 贴顶（贴合背景图顶部横线）、`"center"` 居中 | `"center"` |
| `dialogue` | `textAlign` | 正文水平对齐：`"left"` / `"center"` / `"right"` | `"left"` |
| `name` | `left` `top` | 角色名框相对文本框的偏移 | `0.03 / -0.07` |
| `sprite` | `bottom` `height` | 立绘贴底偏移 / 高度（`"auto"` 自适应） | `0.00 / "auto"` |
| `nvl` | `left` `width` `lineGap` `justify` `textAlign` | NVL 整屏旁白布局 | `0.1875 / 0.625 / "0.5em" / "center" / "left"` |
| `choice` | `left` `top` `width` `gap` `maxWidth` | 选项布局 | `0.10 / 0.26 / 0.80 / "1.2em" / "60%"` |
| `toolbar` | `height` `gap` | 底部工具栏高度与间距 | `"6.5em" / "2em"` |

### 2.13 panel（游戏内暂停菜单浮层）

游戏内暂停菜单 = 点击舞台底部「菜单」按钮（或按 ESC）弹出的浮层。它的按钮、停靠方向、窗口尺寸都由 `panel` 控制。

| 字段 | 类型 | 必填 | 说明 | 默认值 |
|---|---|---|---|---|
| `side` | string | 否 | 浮层停靠方向：`"left"` / `"right"` / `"center"` | `"right"` |
| `width` | number | 否 | 浮层窗口宽（**px**，相对 `screen.designWidth` 转换为比例，构建期翻译）。`center` 停靠时即居中宽度 | `500` |
| `height` | number | 否 | 浮层窗口高（**px**，相对 `screen.designHeight` 转换为比例）。缺省为整屏高（顶部到底部贯穿） | 整屏高 |
| `buttons` | string[] | 否 | 浮层按钮顺序。键见 §2.17 可选键，另支持 `title`（回到首页）与 `back`（返回 / 关闭浮层）。未列出的不显示 | `["save","load","settings","chapters","gallery","about","title","back"]` |

`width` / `height` 的 px→比例换算与 定义.md「按钮以 px 为单位 → 比例」一致：例如 `screen.designWidth=1920` 时 `width:500` 即 `500/1920≈26%`。设置 `height` 后浮层变为垂直居中的定高窗口（不再贯穿整屏）。

```json
{
  "panel": {
    "side": "right",
    "width": 500,
    "buttons": ["save", "load", "settings", "chapters", "gallery", "about", "title", "back"]
  }
}
```

### 2.14 notifyYpos / skipYpos

| 字段 | 类型 | 必填 | 说明 | 默认值 |
|---|---|---|---|---|
| `notifyYpos` | number | 否 | 通知条距顶距离（设计像素） | `68` |
| `skipYpos` | number | 否 | 快进提示距顶距离（设计像素） | `15` |

### 2.15 info

游戏基本信息。

| 字段 | 类型 | 必填 | 说明 | 默认值 |
|---|---|---|---|---|
| `name` | string | 否 | 游戏名（首页标题显示） | — |
| `version` | string | 否 | 游戏版本号（首页标题页与关于页展示） | — |

注意：`info.json` 不含引擎版本。引擎版本由**打包的 aliceADV 引擎包**（`ENGINE_NAME` / `ENGINE_VERSION`）在构建时自动注入产物，显示在标题页与关于页，无需在工程里手动维护。

注意：`info.json` 中的同名键会在构建时**覆盖**本对象（见第 6 节）。

### 2.16 about

`string`。关于页正文，支持 `\n` 分段。通常与工程根 `about.txt` 内容一致。

### 2.17 sidebar

`string[]`。游戏内通用菜单页（存档 / 读档 / 设置 / 章节 / 分支 / 画廊）左侧（或右侧）的导航按钮顺序。只列出想显示的键，顺序即显示顺序；未列出的按钮不显示。

可选键：`history` `save` `load` `settings` `chapters` `gallery` `branches` `about` `back`。

```json
{
  "sidebar": ["history", "save", "load", "settings", "chapters", "gallery", "branches", "about", "back"]
}
```

限制：本键只控制「游戏内通用菜单页的侧栏」。游戏内按 ESC 弹出的暂停菜单（右侧浮层）目前为引擎固定项，暂不受 `theme.json` 控制。

## 3. pages 子树

`pages` 下每个键对应一个页面对象。通用字段：

| 字段 | 适用页面 | 说明 |
|---|---|---|
| `background` | 多数页面 | 页面背景图（工程根相对路径） |
| `title` | save/load/settings/chapters/branches/gallery | 页面中文标题 |
| `titleEn` | 同上 | 页面英文副标题 |

### 3.1 pages.title（首页）

首页是配置项最多的页面，详见第 4、5 节。

### 3.2 pages.save / pages.load

| 字段 | 类型 | 必填 | 说明 | 默认值 |
|---|---|---|---|---|
| `background` | string | 否 | 背景图 | `"gui/game_menu.png"` |
| `title` | string | 否 | 中文标题 | `"保存"` / `"读档"` |
| `titleEn` | string | 否 | 英文副标题 | `"Save"` / `"Load"` |
| `slotRows` | number | 否 | 槽位行数（实际生效） | `2` |
| `slotCols` | number | 否 | 槽位列数（实际生效） | `3` |
| `autoSlots` | number | 否 | 保留字段，**当前运行时未消费**，请勿依赖 | `9` |

槽位实际数量为 `slotCols × slotRows`。存档页第 1 个为自动存档槽、第 2 个为快速存档槽（系统槽不可手动覆盖，详见 `指令.md` 存档章节）；关闭对应开关后该槽从界面消失。

### 3.3 pages.settings

`background` / `title` / `titleEn`。内部控件（显示模式、快进选项、音量滑块等）由引擎固定渲染，暂不可通过 `theme.json` 增删。

### 3.4 pages.chapters / pages.branches

`background` / `title` / `titleEn`。列表内容来自 `story/chapters.json`，不在此处配置。若 `story/chapters.json` 中没有对应条目，页面显示为空。

### 3.5 pages.gallery

| 字段 | 类型 | 必填 | 说明 | 默认值 |
|---|---|---|---|---|
| `background` | string | 否 | 背景图 | `"gui/game_menu.png"` |
| `title` | string | 否 | 中文标题 | `"画廊"` |
| `titleEn` | string | 否 | 英文副标题 | `"Gallery"` |
| `cols` | number | 否 | 画廊每行列数 | `4` |

### 3.6 pages.stage（舞台）

| 字段 | 类型 | 必填 | 说明 | 默认值 |
|---|---|---|---|---|
| `background` | string | 否 | 舞台兜底背景图（剧本未运行时显示） | — |
| `toolbar` | string[] | 否 | 底部工具栏按钮顺序，每个键独立可开关 | 见下 |

`toolbar` 可选键：`back`（后退一句）、`history`（历史）、`skip`（快进）、`auto`（自动）、`save`（保存）、`qsave`（快速存档）、`qload`（快速读档）、`menu`（菜单/暂停）、`load`（读档）。

```json
{
  "pages": {
    "stage": {
      "background": "images/bg/roof.png",
      "toolbar": ["back", "history", "skip", "auto", "save", "qsave", "qload", "menu"]
    }
  }
}
```

要关闭某个工具栏按钮，从数组中删除对应键即可。例如多数游戏不做「后退一句」，就不列 `back`。

### 3.7 pages.about

`background` 等通用字段可用。

## 4. 首页布局：pages.title

### 4.1 layout

`string`。可选值 `left` / `center` / `right` / `bottom` / `custom`。

| 值 | 说明 |
|---|---|
| `left` | 左侧白底栏 + 右侧背景图，按钮靠左 |
| `center` | 按钮居中堆叠，无白色底 |
| `right` | 右侧白底栏，按钮靠右 |
| `bottom` | 按钮在底部一排，上方为全屏背景 |
| `custom` | 使用 `customButtons` 图片热区，完全替代默认按钮列表 |

### 4.2 background / showName / showVersion

| 字段 | 类型 | 说明 | 默认 |
|---|---|---|---|
| `background` | string | 首页背景图路径 | `"gui/main_menu.png"` |
| `showName` | boolean | 是否显示游戏名 | `true` |
| `showVersion` | boolean | 是否显示版本号 | `true` |

### 4.3 buttons（文字按钮列表，控制显示/隐藏）

`string[]`。首页默认按钮列表。**只列出要显示的键，顺序即显示顺序；未列出的按钮不渲染。** 这是控制首页按钮「显示/隐藏」的第一种机制。

支持的键：`start` `continue` `load` `settings` `chapters` `gallery` `branches` `about` `quit`。

默认顺序：

```json
{
  "pages": {
    "title": {
      "layout": "left",
      "buttons": ["start", "continue", "load", "settings", "chapters", "gallery", "branches", "about", "quit"]
    }
  }
}
```

隐藏画廊按钮：从数组中删除 `"gallery"` 即可。隐藏分支按钮：删除 `"branches"`。隐藏继续按钮：删除 `"continue"`。

### 4.4 customButtons（图片热区，完全替代 buttons）

`object[]`。配置后，**`buttons` 列表不再渲染**，首页按钮改为背景图上的透明/图片热区。这是控制首页按钮「显示/隐藏」的第二种机制，且能精确对齐主菜单美术图上的按钮。

每个热区对象的字段：

| 字段 | 类型 | 必填 | 说明 | 默认值 |
|---|---|---|---|---|
| `action` | string | 是 | 按钮功能，见 4.5 取值表 | — |
| `left` | number | 是 | 热区左缘（0~1，相对设计画布宽） | — |
| `top` | number | 是 | 热区上缘（0~1，相对设计画布高） | — |
| `width` | number | 是 | 热区宽（0~1） | — |
| `height` | number | 是 | 热区高（0~1） | — |
| `image` | string | 否 | 按钮图片（工程根相对）；提供后渲染为图片按钮 | — |
| `hover` | string | 否 | 悬停态图片；需配合 `image` | — |
| `label` | string | 否 | 无 `image` 时的文字标签（叠在热区上） | — |

示例：

```json
{
  "pages": {
    "title": {
      "layout": "custom",
      "background": "gui/main_menu.png",
      "showName": false,
      "showVersion": false,
      "customButtons": [
        { "action": "start",    "left": 0.02, "top": 0.70, "width": 0.22, "height": 0.10 },
        { "action": "continue", "left": 0.02, "top": 0.57, "width": 0.20, "height": 0.10 },
        { "action": "load",     "left": 0.02, "top": 0.83, "width": 0.20, "height": 0.10 },
        { "action": "settings", "left": 0.76, "top": 0.72, "width": 0.20, "height": 0.10 },
        { "action": "about",    "left": 0.80, "top": 0.30, "width": 0.12, "height": 0.08 },
        { "action": "quit",     "left": 0.82, "top": 0.14, "width": 0.10, "height": 0.07 }
      ]
    }
  }
}
```

坐标语义：`left/top/width/height` 是相对整张背景图（设计画布 1920×1080）的归一化值。例如 `left:0.02, top:0.70, width:0.22, height:0.10` 表示热区左缘在 2% 宽度处、上缘在 70% 高度处、宽 22%、高 10%。

### 4.5 首页按钮 action 取值表

| action | 跳转 / 行为 | 备注 |
|---|---|---|
| `start` | 开始游戏（第一个可玩章节） | 自动绑定首章剧本 |
| `continue` | 从自动存档继续 | 自动存档关闭或无存档时按钮置灰失效；显示与否由列表/`customButtons` 控制 |
| `load` | 打开读档页 | 标签为「读取存档」 |
| `settings` | 打开设置页 | — |
| `chapters` | 打开章节选择页 | — |
| `gallery` | 打开画廊页 | — |
| `branches` | 打开剧情分支页 | 多数游戏不提供，不列即可 |
| `about` | 打开关于页 | — |
| `help` | 同 `about` | 兼容「主菜单放 Help」的游戏 |
| `quit` | 退出确认弹窗 | — |

其中 `continue` 的特殊性：它的「有效性」由存档系统决定（自动存档开启且存在自动存档才可用），但「是否显示」完全由你是否在 `buttons` / `customButtons` 中列出决定——引擎不擅自隐藏它。若已关闭自动存档（`info.json` 的 `autoSave:false`），应在 `theme.json` 中自行移除 `continue`，否则首页会显示一个置灰、点击无效的按钮。

### 4.6 backgroundSize（热区对齐关键）

`string`。首页背景图的铺满方式。

| 值 | 说明 | 适用 |
|---|---|---|
| `"cover"` | 保持比例铺满，可能裁切 | 装饰性背景、普通布局 |
| `"contain"` | 保持比例完整显示，可能留边 | 需完整看到图片内容 |
| `"100% 100%"` | 拉伸铺满整张画布，1:1 映射坐标 | 自定义热区（`customButtons`）默认 |

**自定义热区模式下，默认值为 `"100% 100%"`**，即背景图被精确映射到设计画布，使 `customButtons` 的 0~1 坐标与图片像素 1:1 对应，从而保证热区与图上按钮严格对齐。若你的主菜单图不是 16:9，请显式指定 `backgroundSize`：

```json
{
  "pages": {
    "title": {
      "layout": "custom",
      "background": "gui/main_menu.png",
      "backgroundSize": "100% 100%",
      "customButtons": [ ... ]
    }
  }
}
```

建议：主菜单背景图直接按 `screen` 设定的分辨率（默认 1920×1080）制作，此时 `cover` 与 `100% 100%` 等价，且热区坐标计算最直观。

### 4.7 debugHotzones（对齐调试）

`boolean`。设为 `true` 时，每个自定义热区显示红色虚线边框与 `action` 名称，便于核对热区是否准确覆盖图上按钮。

```json
{
  "pages": {
    "title": {
      "layout": "custom",
      "debugHotzones": true,
      "customButtons": [ ... ]
    }
  }
}
```

调试完成后改为 `false` 或删除该键即可。

## 5. 首页按钮显示/隐藏：两种机制对照

| 机制 | 配置位置 | 控制方式 | 适用场景 |
|---|---|---|---|
| 列表法 | `pages.title.buttons` | 数组里只保留要显示的键 | 文字按钮、需要统一风格 |
| 热区法 | `pages.title.customButtons` | 数组里只保留要显示的热区；配置后 `buttons` 失效 | 主菜单美术图自带按钮、需像素对齐 |

两种方法都支持 `gallery` / `branches` / `settings` / `about` 等按钮的显示与隐藏——从对应数组中删除该键即可。引擎不会写死任何默认按钮，首页只渲染你在 `theme.json` 中显式列出的按钮。

## 6. info.json 覆盖字段

构建时，`info.json` 的以下键会合并进 `theme.info`（同名覆盖）：

| 键 | 说明 |
|---|---|
| `name` `version` | 游戏名 / 游戏版本号（均覆盖 `theme.info` 同名键） |
| `autoSave` | 是否启用自动存档（默认 `true`） |
| `quickSave` | 是否启用快速存档（默认 `true`） |
| `preload.boot` | 启动加载策略（默认 `"title"`） |
| `preload.runtime` | 运行时预加载策略数组（默认 `["page","predict"]`） |

`autoSave` / `quickSave` 关闭后的连锁影响：

| 开关 | 影响 |
|---|---|
| `autoSave:false` | 自动存档槽从存档/读档页消失；首页「继续」按钮置灰失效；但按钮是否显示仍由 `theme.json` 决定 |
| `quickSave:false` | 快速存档槽从存档页消失；菜单「快存 / 快读」与工具栏对应按钮失效 |

`preload` 详见 [附录 A](#附录-a-加载策略infojson-preload)。

## 7. 自定义主菜单热区对齐工作流

1. 按 `screen.designWidth × designHeight`（默认 1920×1080）制作主菜单背景图，图上按钮位置即最终位置。
2. 用图像工具量出每个按钮的像素坐标，换算为 0~1：
   - `left = 按钮左缘像素 / 画布宽`
   - `top = 按钮上缘像素 / 画布高`
   - `width = 按钮宽像素 / 画布宽`
   - `height = 按钮高像素 / 画布高`
3. 在 `pages.title.customButtons` 中按 `action` 填入上述坐标，设 `layout:"custom"`。
4. 临时设 `debugHotzones:true` 构建预览，核对红框是否准确覆盖图上按钮；偏差则回到第 2 步微调。
5. 核对无误后设 `debugHotzones:false`，并确认 `backgroundSize` 为 `"100% 100%"`（自定义模式默认即此值）。

注意：热区坐标是相对整张画布（0~1），不是相对某个局部容器。只要背景图按设计分辨率制作且 `backgroundSize` 为 `100% 100%`，热区与图上按钮必然 1:1 对齐。

## 8. 维护约定（重要）

`theme.json` 的每一项都对应 `theme.js`（`buildTitlePage` / `applyThemeVars` 等）与构建机制（`builder.py`）的具体实现。以下规则适用于本仓库：

- 修改 `theme.js`、`engine.js`、构建机制，或新增 / 修改 `theme.json` 的字段、语义时，**必须同步更新本文档**，并在变更说明中明确指出「引擎已更新 + 文档已更新」。
- 本文档存在两份、须保持一致：项目根 `documents/样式控制.md` 与引擎模板 `core/documents/样式控制.md`。
- 任何字段新增时，在对应小节补充字段表（类型 / 必填 / 说明 / 默认值）；任何字段废弃时，在表中标注「当前未消费」而非直接删除说明，避免读者误解。

## 附录 A 加载策略（info.json preload）

`preload` 字段在构建时合并进 `theme.info`，由 `preload.js` 模块（`AliceADVPreload`）读取执行。它控制两件事：进入游戏时的启动遮罩行为（强制加载什么才放行玩家）、进入游戏后的运行时网络优化。

### A.1 preload.boot

启动时强制加载的素材范围；加载完（或总超时 12s 兜底）后渐隐 `#boot-mask` 启动遮罩（纯黑 + 转圈圈），玩家方可交互。

| 取值 | 加载范围 | 默认 |
|---|---|---|
| `"none"` | 不强制加载，遮罩立即消失 | — |
| `"title"` | 首页素材：`pages.title.background` + `customButtons` 的 `image` / `hover` | **✓** |
| `"system"` | 首页 + 各启用系统页背景 + 舞台背景；`gallery` / `branches` / `chapters` 对应目录为空视为禁用，跳过其专属素材 | — |
| `"title+story"` | 首页 + 全部剧情素材（所有剧本的 `bg` / `show` / `music` / `sound` / `voice` src + 角色档案全部立绘 + 角色专属对话框） | — |

`"title"` 作为默认值的依据：只等首页（启动快），又避免首页背景「慢慢浮出」，对多数游戏是最佳折中。`"system"` 与 `"title+story"` 启动更慢，分别适用于担心系统页切换空白、或愿意接受较长启动以换取进入游戏后零加载延迟的场景。

### A.2 preload.runtime

运行时预加载策略数组。可任意组合以下键，也可设为 `[]` 表示关闭。

| 键 | 行为 |
|---|---|
| `"page"` | 切换页面前后台预加载目标页背景（不阻塞切换） |
| `"predict"` | 剧情推进时向前扫描 14 条指令，按「音效 / 音乐（最高）→ 语音 → 场景背景 → 角色立绘」串行预取；音效最易「突变」，故优先级最高 |
| `[]` | 关闭运行时预加载，逐行扫描式惰性加载 |

默认值 `["page","predict"]` 的依据：组合即可获得「页面切换平滑 + 剧情资源就绪」的体验，且不引入可感知副作用。

### A.3 启动遮罩细节

- 遮罩 DOM（`#boot-mask` + `.boot-spinner`）写死在 `index.html`，CSS 默认 `opacity:1` + `pointer-events:all`，进入网页即显示纯黑 + 转圈圈。
- `AliceADVPreload.boot()` 完成后调用 `hideMask()`：加 `is-hidden` 类触发 0.45s 渐隐，渐隐完成后 `pointer-events:none`。
- 单资源预加载超时 8s；启动总超时 12s（兜底，避免单个坏资源无限卡玩家）。
- 模板模式且无 `theme.json`（如直接 `file://` 打开模板）时，遮罩无意义，`bootstrap` 立即 `hideMask()` 并给出使用说明。

### A.4 禁用功能的联动

`preload.boot="system"` 与 `"page"` 预加载会先调用 `isPageEnabled` 判断某功能是否启用：`gallery` / `branches` / `chapters` 对应的 `story/chapters.json` 目录数组为空视为禁用，跳过其专属素材的预加载（其余系统页 `save` / `load` / `settings` / `about` 始终启用）。

### A.5 速查表

最小配置：

```json
{
  "preload": {
    "boot": "title",
    "runtime": ["page", "predict"]
  }
}
```

| 场景 | 推荐配置 |
|---|---|
| 普通游戏 | `boot:"title"`, `runtime:["page","predict"]`（默认值） |
| 极小游戏 / 本地调试 | `boot:"none"`, `runtime:[]` |
| 担心系统页切换闪烁 | `boot:"system"`, `runtime:["page","predict"]` |
| 剧情资源总量可控、追求进入游戏后零加载延迟 | `boot:"title+story"`, `runtime:["predict"]` |
