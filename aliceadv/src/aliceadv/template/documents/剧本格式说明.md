# aliceADV 剧本格式说明

> 适用版本：core 引擎 + 由 create.py 创建的工程目录。本文与 `core/story/ch1.json`、`ch2.json`、`characters.json`、`chapters.json` 实测一致。

---

## 1. 引擎与工程目录结构（与 Ren'Py 兼容）

aliceADV 是一个 pip 安装的 Python 包，分为两层：

- **`aliceadv` 包 —— 引擎（你不需要、也不应该修改它）**
  - 包内 `template/` 目录是「工程模板」（index.html / style/ / gui/ / images/ / audio/ / story/ / theme.json / info.json / documents/），纯数据、与编译器实现解耦，便于将来移植到其他语言。
  - 命令行 `aliceadv create` 把模板搭成一个新工程目录；`aliceadv build` 对工程构建，输出到 `<工程>/dist/web/`。
  - 模板目录内的 `.aliceadv_engine` 是引擎标记文件，`build` 用它拒绝「直接 build 引擎模板」。
- **你的「工程目录」——由 `aliceadv create` 创建，你在里面做所有自定义**

```
<工程目录>/
├── theme.json              # ⚠️ 只管「样式」与「界面文本/导航」，不含任何目录数据
├── info.json               # 游戏名 / 版本等（create.py 可写入，或你手动改）
├── gui/                    # 界面图片（Ren'Py 约定：文本框/按钮/面板/叠加层）
│   ├── main_menu.png       # 主菜单背景
│   ├── game_menu.png       # 游戏内菜单背景
│   ├── textbox.png         # 默认对话框图片（角色未指定 textbox 时使用）
│   ├── textbox_dark.png    # 角色专属深色对话框（示例）
│   ├── namebox.png         # 名字框
│   ├── frame.png           # 面板/弹窗边框
│   ├── sample_character.png
│   ├── sample_thumb.png
│   ├── button/             # 按钮背景（Ren'Py 约定子目录）
│   │   ├── idle_background.png
│   │   ├── hover_background.png
│   │   ├── choice_idle_background.png
│   │   └── choice_hover_background.png
│   └── overlay/            # 叠加暗化层（Ren'Py 约定子目录）
│       ├── main_menu.png
│       ├── game_menu.png
│       └── confirm.png
├── images/                 # 游戏内容图片（Ren'Py 约定：背景/立绘/CG）
│   ├── bg/                 #   - 背景：images/bg/xxx.png
│   └── char/<角色id>/      #   - 立绘：images/char/elin/normal.png
├── audio/                  # 音频（Ren'Py 约定：audio/）
│   └── rooftop.wav         #   - 音乐/音效
├── story/                  # 剧本（每章一文件 + 目录）
│   ├── characters.json     # 角色档案
│   ├── chapters.json       # 剧本目录：章节列表 + 播放顺序 + 分支 + 画廊
│   ├── ch1.json            # 第一章剧本
│   └── ch2.json            # 第二章剧本
└── documents/              # 本文档
```

> 注：工程目录只保存「内容」——引擎运行时（`index.html` / `style/`）不进工程，由 `aliceadv build` 构建时从包内模板装配进 `<工程>/dist/web/`。

**设计原则（重要）**

- `core/` 是**引擎模板**：不写死任何游戏默认内容；用户自定义内容都在自己工程里的 `theme.json` 与各 `story/*.json`。
- 你**不修改 `core/`**，而是在自己的工程目录里改 `theme.json`、写 `story/` 等，然后运行 `build.py <工程目录>` 生成 `<工程>/dist/web/`。严禁对 `core/` 直接执行 build。
- `theme.json` **只负责样式管理与界面文本**（颜色/字号/布局相对值、面板停靠方向 `panel.side`、按钮文案、页面导航顺序）。章节目录、分支、画廊等「目录数据」不在 `theme.json` 里，统一由 `story/chapters.json` 管理。
- 图片目录与 Ren'Py 完全兼容：
  - `gui/` —— 界面图片（文本框、按钮、面板、叠加层），含 `button/`、`overlay/` 子目录；
  - `images/` —— 游戏内容图片（背景、立绘、CG）；
  - `audio/` —— 音频。
- 构建机制（`build.py`）读取工程的 `theme.json`+`info.json`，把相对值(0~1)翻译为百分比 CSS 变量，并把 `story/` 下全部 JSON 内联进 `<工程>/dist/web/`，使 `file://` 直接双击即可游玩。

## 2. 角色档案 `story/characters.json`

每个角色一个对象，结构化放一起：

```json
{
  "narrator":   { "name": "", "sprites": {}, "textbox": null },
  "protagonist":{ "name": "我", "color": "#5C5757", "sprites": {}, "textbox": null },
  "elin": {
    "name": "艾琳",
    "initialName": "？？？",                       // 开局未知名字时显示，剧本 rename 揭示真名
    "color": "#3B5998",
    "textbox": "gui/textbox_dark.png",            // 角色专属对话框图片（位于 gui/，可选；不填用默认 gui/textbox.png）
    "sprites": {
      "normal":   "images/char/elin/normal.png",  // 立绘位于 images/char/<角色id>/
      "smile":    "images/char/elin/smile.png",
      "surprise": "images/char/elin/surprise.png"
    }
  }
}
```

| 字段 | 说明 |
|------|------|
| `name` | 角色真名（rename 后使用）。 |
| `initialName` | 开局未知名字时显示（如 `？？？`）。运行时按「当前显示名」规则展示，rename 指令改为 `name`。 |
| `color` | 名字标签颜色（可选）。 |
| `textbox` | 该角色说话时使用的对话框图片路径（**位于 `gui/`**）。不填则使用默认纸感/图片对话框。 |
| `sprites` | 表情→图片路径映射，图片位于 `images/char/<角色id>/`。 |

## 3. 剧本目录 `story/chapters.json`

章节/分支/画廊等「目录数据」集中在此，引擎从中读取，与 `theme.json` 解耦：

```json
{
  "playOrder": ["ch1", "ch2"],              // 播放顺序（章节 id 序列）
  "chapters": [
    { "idx": "01", "id": "ch1", "title": "序章", "desc": "天台上的相遇", "locked": false, "script": "story/ch1.json" },
    { "idx": "02", "id": "ch2", "title": "日常", "desc": "教室里的午后", "locked": false, "script": "story/ch2.json" },
    { "idx": "03", "id": "ch3", "title": "相遇", "desc": "新角色的登场", "locked": true }
  ],
  "branches": [ { "idx": "A", "title": "原谅她", "desc": "理解并继续", "locked": false } ],
  "gallery":  [ { "name": "Eileen 微笑", "locked": false } ]
}
```

| 字段 | 说明 |
|------|------|
| `playOrder` | 章节播放顺序（id 序列），用于顺序衔接。 |
| `chapters[].idx` | 序号（展示用）。 |
| `chapters[].id` | 章节唯一 id。 |
| `chapters[].title` / `desc` | 标题 / 简介（章节选择页展示）。 |
| `chapters[].locked` | 是否锁定（锁定项不可进入）。 |
| `chapters[].script` | 剧本文件路径（如 `story/ch1.json`）；无 script 且未锁定时表现为「敬请期待」。 |
| `branches` / `gallery` | 分支、画廊目录（结构同上，按需扩展）。 |

> 开始游戏按钮会自动绑定 `chapters` 中第一个 `locked:false` 且含 `script` 的章节。

## 4. 章节剧本 `story/chX.json`

每章一个 JSON 文件。结构：

```json
{
  "id": "ch1",
  "title": "序章 · 天台的风",
  "start": "seg_intro",                // 起始段
  "segments": {
    "seg_intro": [ ...指令... ],
    "seg_ask_name": [ ... ],
    "seg_ending": [ ... ]
  }
}
```

- 剧情按「**段(segments)**」组织，段之间用 `goto` 或判定（`decide`）跳转。
- 段内是**指令数组**，按顺序执行；遇到「阻塞指令」（`say`/`narrate`/`title`/`decide`/`wait`/`end`）即暂停，等待玩家点击推进，再继续后续非阻塞指令。
- 非阻塞指令（`bg`/`music`/`sound`/`stop`/`show`/`hide`/`sprite`/`rename`/`goto`/`nvlclear`）执行后立即继续，直到遇到阻塞指令或段结束。
- `wait` 期间的等待可被点击跳过（先点一下补完/跳过等待，再点一下继续）。

### 指令全集

| cmd | 字段 | 阻塞 | 说明 |
|-----|------|------|------|
| `bg` / `scene` | `src`, `transition?`("fade") | 否 | 切换背景（单槽替换式）。`scene` 为规范名，`bg` 保留作兼容别名，二者等价。`src` 位于 `images/bg/`，`transition:"fade"` 淡入淡出。 |
| `music` | `src`, `loop?`, `fade?`, `volume?`, `ifChanged?` | 否 | 音乐（**默认无限循环**，像 CSS 动画直到 `stop` 指令）。`src` 位于 `audio/`；`loop` 缺省/`true`/`"INF"`=无限，`false`/`0`=一次性，正整数 `N`=播 N 次自动停；`fade`=淡入秒数；`volume`=音量(0~1)；`ifChanged`=同曲已播则不重启。 |
| `sound` | `src`, `volume?` | 否 | 音效（**一次性，不循环**）。独立「音效通道」，与 `music` 互不干扰（可同时播放）。无需对应停止指令。 |
| `voice` | `src`, `volume?` | 否 | 一次性语音（独立「语音通道」，无台词时也可独立播放）；更常见是绑在 `say` 上：`say{ voice:"audio/x.ogg", voiceVolume?:0.9 }`（随该句显示自动播放，回溯也重播）。 |
| `stop` | `what`("music"/"sound"/"voice"/"all"), `fade?` | 否 | 停止音频：`music` 停音乐、`sound` 停音效、`voice` 停语音、`all` 全停。`fade` 为淡出秒数（如 `fade:1.0`，对齐 Ren'Py `stop music fadeout`）。 |
| `show` | `char?`, `sprite?`, `src?`, `at?`("left"/"center"/"right"), `transition?`("fade"), `anim?` | 否 | 立绘/图片出现。① `char`+`sprite` 查角色档案 `sprites`；② `src` 直接显示一张图片（如 demo 的生物 / 道具，无需角色档案）。`at` 站位；`transition:"fade"` 淡入；`anim` 出现动画(fade/bounce/shake/slide-left)。 |
| `hide` | `char?`/`src?`, `transition?`("fade"), `anim?` | 否 | 立绘/图片消失。与 `show` 用同一把匹配键（`char` 或 `src`）。 |
| `sprite` | `char`, `sprite`, `anim?` | 否 | 切换立绘/表情（不改站位）。 |
| `say` | `char`, `text`, `sprite?`, `as?`, `append?`, `pause?`, `voice?`, `voiceVolume?` | 是 | 角色说话。自动套用该角色档案的 `color`（名字颜色）与 `textbox`（专属对话框图片）。`as` 为临时显示名（不改档案）。`voice`/`voiceVolume` 见上文「语音」。`append:true` 把本句**拼接**到上一句（不清空对话框、历史合并为同一条、段间可插任意指令做「变脸色再续说」）；`pause:N`(秒) 让拼接段自动续播，省略则等同普通句等点击。 |
| `narrate` | `text`, `mode?`("nvl") | 是 | 旁白（名字为空）。`mode:"nvl"` 走 **NVL 整屏模式**：文本逐行累积覆盖整屏、可滚动，直到 `nvlclear` 清空；普通 `narrate` 仍走底部文本框。 |
| `nvlclear` | — | 否 | 清空 NVL 整屏累积文本（对应 Ren'Py `nvl clear`）。 |
| `rename` | `char`, `to` | 否 | 角色改名（如 `？？？` → 真名）。 |
| `decide` | `prompt?`, `options:[{text,goto,record?,set?,value?}]` | 是 | 判定/选项分支。点选项后 `goto` 指定段；`record:"变量名"` 把该选项文本（或 `value`）写入全局变量；`set:[{var,op,value}]` 批量写变量（见下文「变量与分支」）。 |
| `goto` | `segment` | 否 | 跳转到段。 |
| `set` | `var`, `op?`("="\|"add"\|"sub"\|"mul"\|"div"\|"toggle"\|"append"), `value?` | 否 | 写全局变量（非阻塞）。`op` 缺省为赋值 `=`；`add/sub/mul/div` 数值运算；`toggle` 布尔取反；`append` 数组追加或字符串拼接。变量无需预声明，`set` 会自动建。 |
| `if` | `test`(表达式) 或 `var`+`op`+`value`, `goto?`, `else?` | 否 | 条件跳转（非阻塞）。`test` 为安全表达式（见下文），命中则跳 `goto`、未命中跳 `else`；`goto`/`else` 皆空则**继续当前段下一句**。 |
| `_（任意指令）_` | `if:"<表达式>"` | — | **单条指令的执行条件**：字段 `if` 给出表达式，不满足则跳过该指令（不执行、不阻塞，继续推进）。用于「小差异」而不必新开段。 |
| `wait` | `seconds?` / `ms?` | 是 | 演出等待。`seconds`（对应 Ren'Py `pause N` 秒）或 `ms`（毫秒）。等待期间点击可跳过。 |
| `title` | `text` | 是 | 章节标题卡（展示后自动推进）。 |
| `end` | `action?`("title"/"chapters") | 是 | 章节结束。`action:title` 回首页；`action:chapters` 回章节选择。退出播放会清空历史。 |

> **匹配键说明**：`show`/`hide` 用 `nodeId` 唯一标识舞台节点——有 `src` 时用 `__src__<src>`，否则用角色 id。因此「角色立绘」与「直接图片（src）」在舞台上互不覆盖。

### NVL 整屏模式（旁白长段）

Ren'Py 的 `narrator_nvl` + `nvl clear` 对应本引擎的 `narrate{mode:"nvl"}` + `nvlclear`：

```json
[
  { "cmd": "narrate", "mode": "nvl", "text": "忽然脑海里闪回了这样的画面" },
  { "cmd": "narrate", "mode": "nvl", "text": "高二的第一天，新的教室……" },
  { "cmd": "nvlclear" }
]
```

- 连续 `narrate{mode:"nvl"}` 会把每行文本**累积**进整屏面板（`.stage-nvl`），可滚动查看；
- 任意 `say`（角色说话）或普通 `narrate` 会自动隐藏 NVL 面板、切回底部文本框；
- NVL 面板的列宽 / 对齐 / 文字色 / 行距由 `theme.json` 的 `layout.nvl`（left/width/lineGap/justify/textAlign）控制，构建时翻译为 CSS 变量。

### 直接显示图片（`src`，无需角色档案）

demo 中的生物 / 道具（如 `fsm`、`wny`、`sltw1`）不是「说话角色」，只是画面元素。用 `show`/`hide` 的 `src` 直接上屏，引擎不要求它在 `characters.json` 里：

```json
{ "cmd": "show", "src": "images/char/fsm.png", "at": "center" },
{ "cmd": "hide", "src": "images/char/fsm.png" }
```

### 角色语音 `voice`

aliceADV 提供独立的「语音通道」，对齐 Ren'Py 的 `voice`。语音是**一次性**的，不需要对应停止指令。

**写法一（推荐）：绑在 `say` 上** —— 语音随该句台词显示时自动播放，玩家回溯（后退一句）时也会重播：

```json
{ "cmd": "say", "char": "elin", "text": "你好，我是艾琳。", "voice": "audio/elin_hello.mp3", "voiceVolume": 0.9 }
```

**写法二：独立 `voice` 指令** —— 无台词时（如纯背景语音、过场独白）也可单独播放：

```json
{ "cmd": "voice", "src": "audio/narration_01.mp3" }
```

> `voice` 与 `music`/`sound` 相互独立，三者可同时播放；切换台词时新的语音会自动顶掉旧的。`stop{what:"voice"}` 可显式停止。

### 句中停顿与续说（`append` / 行内 `{w}`）

很多游戏里角色会「顿一下再输出后半句」，或「突然想到什么、变脸色再说后半句」。aliceADV 用两套互补机制实现，对齐 Ren'Py 的 `{w}` / `{p}` / `extend`。

**1. 行内停顿 `{w}` / `{w=N}`** —— 写在 `text` 里，打字到该位置时暂停：

- `{w}`：停在此处**等玩家点击**，点击后续打后半句（同一句、不换行）。
- `{w=0.6}`：暂停 0.6 秒后**自动续打**（按 `auto` 开关同理自动）。
- 行内可有多个 `{w}`，分别控制多处停顿。

```json
{ "cmd": "say", "char": "elin", "text": "我本来想说……{w}算了，还是告诉你吧。" }
{ "cmd": "say", "char": "elin", "text": "等一下{w=0.8}我想起来了！" }
```

**2. 多段追加 `append:true`** —— 把本句**拼接**到上一句（不清空对话框、历史合并为同一条），段间可自由插入 `show`/`bg`/`sfx` 等指令。这就是「变脸色再续说」的标准写法：

```json
[
  { "cmd": "say", "char": "elin", "text": "我觉得吧，" },
  { "cmd": "show", "char": "elin", "sprite": "surprise" },
  { "cmd": "say", "char": "elin", "text": "这应该没什么问题。", "append": true, "pause": 0.5 }
]
```

- 拼接后对话框显示「我觉得吧， 这应该没什么问题。」，历史里算**同一句**台词（对应 Ren'Py `extend`）。
- `pause:N`(秒)：拼接段在 N 秒后**自动续播**下一句；**省略 `pause` 则等同普通句——等玩家点击**（最保守、最可控）。
- 自动播放（`auto`）开启时，`pause` 省略也按系统自动速度续播。

> 推荐组合：`{w}` 做简单句中停顿；`append` + 段间 `show` 做「变脸色再续说」这类需要插指令的效果。二者可叠加使用。

### 变量与分支（Story Graph）

aliceADV 的剧情以「**段（segment）**」为发展单元，段与段之间用 `goto`/`if` 跳转，自然构成一张**剧情图（story graph）**——分支可各自发展，再在共同的一段汇合。在段之上还有一层宏观组织「**章（chapter）**」。

**① 章 / Chapter（宏观组织）** —— 把若干段归到一个章节名下，仅作组织与导航元数据；运行时所有段被**扁平化为全局唯一段名**，跳转仍按段名。

```json
{
  "start": "normal",
  "chapters": {
    "Chapter 3": {
      "start": "intro",
      "segments": {
        "intro":  [ { "cmd": "say", "char": "elin", "text": "第三章开始。" } ],
        "normal": [ { "cmd": "say", "char": "elin", "text": "回家。" }, { "cmd": "goto", "segment": "common" } ],
        "mozi":   [ { "cmd": "say", "char": "elin", "text": "走 Mozi 线。" }, { "cmd": "goto", "segment": "common" } ],
        "common": [ { "cmd": "say", "char": "elin", "text": "两条线在此汇合。" } ]
      }
    }
  }
}
```

**② 段 / Segment（真正的剧情单元）** —— 一段就是一段事件/剧情。跳转全部发生在段级，而不是逐句。

**③ 变量（全局，游玩期内有效）**

- 脚本根 `"vars": { "favor": 0, "place": "" }` 声明初始值（可选，`set` 也能自动建变量）。
- 运行时 `state.vars` 全局共享；`start()` / `exit()` 清零。
- 安全表达式：仅支持 `变量 / 数字 / 字符串 / 比较(== != >= <= > <) / 逻辑(&& || !) / 算术(+ - * /) / 括号`，**不使用 `eval`**，杜绝注入。

**写变量 `set`**

```json
{ "cmd": "set", "var": "favor", "op": "add", "value": 1 }   // favor += 1
{ "cmd": "set", "var": "met", "op": "toggle" }              // 布尔取反
{ "cmd": "set", "var": "place", "value": "医院" }           // 赋值
```

**条件跳转 `if`**（两种等价写法）

```json
{ "cmd": "if", "test": "favor >= 3 || place == '医院'", "goto": "good_end", "else": "normal_end" }
{ "cmd": "if", "var": "favor", "op": ">=", "value": 3, "goto": "good_end", "else": "normal_end" }
```

命中 `test` → 跳 `goto`；未命中 → 跳 `else`；两者皆空 → **继续当前段下一句**（不跳转）。

**选项记录变量 `decide`**

```json
{ "cmd": "decide", "prompt": "你要去哪？", "options": [
    { "text": "医院", "goto": "route_hospital", "record": "place", "set": [ { "var": "favor", "op": "add", "value": 1 } ] },
    { "text": "学校", "goto": "route_school", "record": "place" }
] }
```

选「医院」→ `place="医院"` 且 `favor += 1`；之后用 `if{ test:"favor>=3" }` 或 `if{ test:"place=='医院'" }` 分流。

**两种「小差异」写法（避免为一点差别新开段）**

1. **行内条件文本 `{if}`** —— 写在 `text` 里，渲染时按 `state.vars` 实时选择分支（支持 `elif` / `else`）：

```json
{ "cmd": "say", "char": "elin", "text": "我喜欢喝奶茶。{if chap4_go_home_selected: \"噢对了你昨天晚上xxx\"; else: \"下次一起去xxx吧！\"}" }
```

2. **单条指令执行条件 `if`** —— 给任意指令加 `if` 字段，条件不满足则该指令**整条跳过**（少一句）：

```json
[
  { "cmd": "say", "char": "elin", "text": "我喜欢喝奶茶。" },
  { "cmd": "say", "char": "elin", "text": "噢对了你昨天晚上xxx", "if": "chap4_go_home_selected" }
]
```

不满足 `chap4_go_home_selected` 时，第二句直接不出现。

> 设计原则：**大节点用段（segment）做分支/汇合，小差异用 `{if}` 行内条件或单指令 `if` 字段**——不要为一点文本差别新建整段。

### 兼容性特性

- **`？？？`→名字**：角色 `initialName` 设为 `？？？`，剧本中 `rename` 指令揭示真名，之后所有 `say` 显示真名。
- **专属对话框 + 名字颜色**：角色 `textbox` 指向 `gui/` 下的图片（如 `gui/textbox/tomoko_tb.png`），`color` 为该角色名字标签颜色；说话时 `say` 自动套用。不填 `textbox` 则用默认对话框。
- **临时名 `as`**：`say` 的 `as` 字段仅本次显示用临时名，不改档案。
- **三音频通道**：`music`（默认无限循环的 BGM，可 `loop:N` 指定次数或 `loop:false` 一次性）、`sound`（一次性 SFX）、`voice`（一次性语音，通常绑 `say`）。`stop` 可按 `what` 分别或全部停止，并支持 `fade` 淡出。音乐语义对齐 Ren'Py 的 `play music`/`stop music fadeout`/`if_changed`，并额外提供 Ren'Py 没有的「播放次数 `loop:N`」，契合 CSS 动画 `animation-iteration-count` 的直觉。

## 5. 新增一章

1. 在 `story/` 下新建 `ch3.json`，按 §4 结构写 `id`/`title`/`start`/`segments`（背景用 `images/bg/`，立绘用 `images/char/<id>/`，音乐用 `audio/`）。


4. 重新运行 `python3 core/build.py <工程目录>` 生成 `<工程>/dist/web/`。

> 无需改动 `theme.json` 即可新增章节——目录由 `story/chapters.json` 驱动。

## 6. 资源路径约定（Ren'Py 兼容）

| 类别 | 目录 | 示例 |
|------|------|------|
| 主菜单/游戏菜单背景 | `gui/` | `gui/main_menu.png`、`gui/game_menu.png` |
| 对话框/名字框/面板 | `gui/` | `gui/textbox.png`、`gui/namebox.png`、`gui/frame.png` |
| 按钮背景 | `gui/button/` | `gui/button/idle_background.png` |
| 叠加暗化层 | `gui/overlay/` | `gui/overlay/game_menu.png` |
| 背景 | `images/bg/` | `images/bg/roof.png` |
| 立绘 | `images/char/<角色id>/` | `images/char/elin/normal.png` |
| 音乐/音效 | `audio/` | `audio/rooftop.wav` |

所有路径在 JSON 中以**相对工程根目录**的形式书写（如 `images/bg/roof.png`、`gui/textbox_dark.png`），构建后 `<工程>/dist/web/` 保持相同相对结构，`file://` 直接可加载。

### CSS 内的资源引用（易踩坑，已由编译器处理）

CSS 的 `url()` 是相对 **CSS 文件自身所在目录**解析的，不是相对 `index.html`；但引擎模板里统一按**工程根相对路径**书写（`url("gui/textbox.png")`），与 JSON 约定保持一致。二者不一致会导致背景 404（表现为对话框/选项按钮/弹窗底图不显示）。

因此由 `core/cssutil.py` 在**编译期按文件深度自动补 `../` 前缀**：

| 文件位置 | 模板写法 | 编译后 |
|---|---|---|
| `style/base.css` | `url("gui/button/idle_background.png")` | `url("../gui/...")` |
| `style/pages/*.css` | `url("gui/textbox.png")` | `url("../../gui/...")` |

该重写**幂等**（先压平已有前缀再重写），`create.py`（新建工程）、`sync_engine.py`（同步引擎）、`build.py`（构建产物）三处共用同一函数，重复执行不会累积 `../`。

> 结论：**模板里照常写 `gui/...`，不要手写 `../../`**；若新增 CSS 文件放到别的深度，编译器会自动适配。

## 7. 创建工程、构建与运行

```bash
# 1) 创建工程（交互输入路径；非空目录会要求二次确认）
python3 core/create.py <工程目录>

# 2) 在自己的工程目录里编写 theme.json / story / info.json / 替换 gui|images|audio 资源

# 3) 构建（输出到 <工程目录>/dist/web/）
python3 core/build.py <工程目录>
```

- 直接双击 `<工程目录>/dist/web/index.html` 即可游玩（无需服务器）。
- 模板模式（直接开工程的 `index.html` 而非构建产物）需本地服务器：`python3 -m http.server` 后访问。

构建会把工程的 `theme.json`+`info.json` 与全部 `story/*.json` 内联进 `dist/web/index.html`（`window.__THEME__` / `window.__SCRIPTS__`），并把主题相对值翻译为 `dist/web/style/theme.built.css`。

> `create.py` 也支持函数调用：`create_project(path, info={"name":"我的游戏"})` 会在复制完成后把游戏名写入 `info.json`，且不做二次确认。

#### 升级引擎后：同步已有工程

工程的 `style/`（运行时代码）与 `index.html` 是**引擎文件**，由 `create.py` 从 `core/` 复制而来、独立冻结。当你升级 `core/` 后，已有工程的引擎文件不会自动更新，需要手动同步：

```bash
python3 core/sync_engine.py <工程目录>
python3 core/build.py <工程目录>      # 同步后再重新构建
```

`sync_engine.py` 只覆盖 `index.html` + `style/`（纯引擎代码），**保留**用户的 `theme.json` / `info.json` / `story/` / `gui/`（含 `textbox/`）/ `images/` / `audio/`，不会误删 demo 专属素材。

### 存档系统（运行时行为）

写作者无需在剧本里写存档指令，引擎自动完成。存档数据持久化于浏览器 `localStorage`。

**三类存档槽**

| 类型 | 触发方式 | localStorage 键 | 可手动覆盖 |
|---|---|---|---|
| 自动存档 | 每前进一步自动写入 | `aliceADV.auto` | 否 |
| 快速存档 | 工具栏「快存」 | `aliceADV.quick` | 否 |
| 普通存档 | 「保存」页点普通槽 | `aliceADV.save.1` … | 是 |

- 自动存档每次前进都更新，供首页「继续」读取（`loadAuto`）。
- 「保存 / 读档」页槽位顺序：自动存档 → 快速存档 → 普通存档；关闭某项系统槽时该槽不显示，普通槽前移补齐。
- 系统槽（自动 / 快速）在「保存」页点击被忽略，玩家无法手动覆盖；三者 `localStorage` 键互不冲突。

**开关（info.json）**

`autoSave`、`quickSave` 缺省均为 `true`。关闭 `autoSave` 时自动存档槽不显示且 `loadAuto` 失败（「继续」失效）；关闭 `quickSave` 时快速存档槽不显示且「快存 / 快读」失败。按钮 / 槽位是否出现在界面由 `theme.json` 控制。

**槽位显示**

- **缩略图**：保存瞬间的背景图（`bg` 当前值）。
- **文字**：说话角色名（改名后显示改名结果）+ 当前台词。旁白显示「旁白」，选项界面显示「选择」+ 提问语。
- **保存时间**：`年/月/日 时:分:秒`（到秒）。

保存成功弹出「已保存」提示（与退出确认框同款样式，约 1.6 秒自动消失，也可点「确定」关闭），不再使用浏览器 `alert`。读档恢复背景、在场角色、当前台词、变量、改名、NVL 整屏、历史记录，回到保存时那一句等待点击；若当时停在选项界面，读档后重建该选项。系统槽在「读档」页可正常读取，保护仅针对手动覆盖。

## 9. 工具：从 Ren'Py 迁移 & 引擎同步

### `core/tools/rpy2adv.py` —— Ren'Py 剧本转 aliceADV

把 Ren'Py Web 构建（`game/script.rpy` + `game/images/`）一键转成 aliceADV 的 `story/` JSON：

```bash
python3 core/tools/rpy2adv.py <script.rpy> <images_dir> <输出story目录>
# 例：
python3 core/tools/rpy2adv.py game/script.rpy game/images girls_orbit_project/story
```

转换规则（已用于 `girls_orbit_project`）：

| Ren'Py | aliceADV |
|--------|---------|
| `scene X with fade` | `{cmd:"bg", src, transition:"fade"}` |
| `show X at center/left/right` | `{cmd:"show", char/src, at}`（角色或生物图片） |
| `hide X` | `{cmd:"hide", char/src}` |
| `pause N` | `{cmd:"wait", seconds:N}` |
| `play music X` / `play sound X` | `{cmd:"music"}` / `{cmd:"sound"}` |
| `stop music` / `stop sound` | `{cmd:"stop", what:"music"/"sound"}` |
| `nvl clear` | `{cmd:"nvlclear"}` |
| `Character('名', color, image, window_background)` | `characters.json` 条目（含 `color`、`textbox`） |

### `core/tools/gui2theme.py` —— Ren'Py 布局转 aliceADV

`rpy2adv.py` 只管剧本，**界面几何**（对话框高度、正文位置、名字条位置、字号、NVL 列宽等）由 `gui.rpy` 决定，应由本工具自动换算，不要手工照抄数字：

```bash
python3 core/tools/gui2theme.py <gui.rpy> <工程>/theme.json            # 预览
python3 core/tools/gui2theme.py <gui.rpy> <工程>/theme.json --apply    # 写入
```

| Ren'Py (`gui.rpy`) | aliceADV (`theme.json`) |
|---|---|
| `gui.init(W,H)` | 设计分辨率基准 |
| `gui.textbox_height` / `textbox_yalign` | `layout.dialogue.height` / `bottom` |
| `gui.dialogue_xpos` | `layout.dialogue.padX`（= xpos/W） |
| `gui.dialogue_ypos` | `layout.dialogue.padTop`（设计像素 px） |
| `gui.name_xpos` / `name_ypos` | `layout.name.left` / `top`（相对文本框） |
| `gui.nvl_thought_xpos` / `_width` / `nvl_spacing` | `layout.nvl.left` / `width` / `lineGap` |
| `gui.choice_button_width` / `choice_spacing` | `layout.choice.width` / `gap` |
| `gui.text_size` / `name_text_size` / `choice_button_text_size` | `sizes.text` / `name` / `choice` |

> 只覆盖算得出的字段，其余配置原样保留；写入的 `_comment` 会标注来源，便于复核。

### 主菜单自定义按钮热区

若游戏主菜单像 demo 一样，按钮文字直接画在背景图上，可在 `theme.json.pages.title` 里配置 `customButtons`，用透明热区覆盖背景图上的按钮位置：

```json
{
  "pages": {
    "title": {
      "layout": "custom",
      "background": "gui/main_menu.png",
      "showName": false,
      "showVersion": false,
      "customButtons": [
        { "action": "start",    "left": 0.02, "top": 0.70, "width": 0.22, "height": 0.10 },
        { "action": "load",     "left": 0.02, "top": 0.83, "width": 0.20, "height": 0.10 },
        { "action": "help",     "left": 0.78, "top": 0.04, "width": 0.12, "height": 0.08 },
        { "action": "quit",     "left": 0.82, "top": 0.14, "width": 0.10, "height": 0.07 },
        { "action": "about",    "left": 0.80, "top": 0.30, "width": 0.12, "height": 0.08 },
        { "action": "settings", "left": 0.76, "top": 0.72, "width": 0.20, "height": 0.10 }
      ]
    }
  }
}
```

- `action`：`start`、`load`、`settings`、`chapters`、`gallery`、`branches`、`about`、`help`（映射到 about）、`quit`。
- 提供 `image`/`hover` 可做成图片按钮；否则为透明热区。
- 配置 `customButtons` 后，默认 `buttons` 列表不再渲染。
| `角色 "台词"` | `{cmd:"say", char, text}` |
| `narrator_nvl "文本"` | `{cmd:"narrate", mode:"nvl", text}` |

- 立绘 `roleX_Y.png` → `images/char/X/Y.png`；生物（无角色）→ `images/char/<名>.png`；
- 角色对话框 `images/xxx_tb.png` → `gui/textbox/xxx_tb.png`（与引擎 Ren'Py 兼容布局一致）。
- 行内 `#` 注释会被剥离，但引号内的 `#`（如 demo 文本里的 `#\%^$`）保留。
