# aliceADV 文档

aliceADV 是一个网页端 ADV（视觉小说）游戏引擎，能轻易创建高性能的视觉小说游戏。

**开发者友好。** 剧本是扁平的 JSON 指令流（段 + 指令），界面由一份 `theme.json` 描述，做一款完整游戏不需要写 Python 或 CSS；这并不意味着束缚，标题、存档、设置、章节、分支、画廊、关于等页面，以及转场、NVL、自动存档、快进、按键映射等功能均有完整实现。

**轻松发布。** 编译后直接产生可静态部署的网页文件（未来可以直接生成各平台安装包），放到 GitHub Pages 之类的免费静态托管上就能让别人在线游玩。网页版带有预加载机制，在较差的网络环境中也能尽力保障使用体验，见[预加载](预加载.md)。

**对 AI 辅助开发友好。** 本文档站与仓库里的处理脚本足够完整，可以直接把仓库链接交给智能体，让它学会使用本引擎；你只需要口述自己的想法。

**部分兼容 Ren'Py。** 素材目录、立绘站位与常见演出语义兼容 Ren'Py 工程，`rpy2adv` / `gui2theme` 两个工具负责换算剧本与布局，字段对应关系见[剧本格式说明](剧本格式说明.md)。

引擎以 Python 包形式发布，未来还会发布一个图形化开发工具。

- 仓库：<https://github.com/Alice-Drop/aliceADV>
- 安装：`pip install aliceadv`

## 五分钟上手

```bash
pip install aliceadv
aliceadv create my_game
aliceadv build my_game
```

用浏览器打开 `my_game/dist/web/index.html` 即可游玩。之后修改 `my_game/theme.json`（样式）与 `my_game/story/*.json`（剧本），每次改完重新执行 `aliceadv build my_game`。

资源目录与 Ren'Py 兼容，迁移时可直接沿用：

| 目录 | 用途 |
|---|---|
| `gui/` | 界面图片（文本框、按钮、面板、叠加层） |
| `images/bg/` | 场景背景 |
| `images/char/<角色id>/` | 角色立绘 |
| `audio/` | 音乐、音效、语音 |

## 文档约定

- 文档的唯一副本位于本目录（引擎仓库 `docs/`），以 GitHub Pages 形式发布。
- 引擎包（`aliceadv`）内不含文档；`aliceadv create` 不会把文档复制进工程。
- 文档与引擎同仓库更新，同一次提交内保持一致，避免出现文档描述与代码不符。
- 工程目录下的 `documents/` 属作者自建内容，`aliceadv build` 会将其排除在发行产物之外。
