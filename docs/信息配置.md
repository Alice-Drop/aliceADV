# 信息配置（info.json 配置手册）

`info.json` 是工程级配置文件，保存游戏的标识信息、存档开关与资源预加载策略。它与 `theme.json` 职责分离：

- `info.json`：游戏身份（`name` / `version`）、存档开关（`autoSave` / `quickSave`）、预加载策略（`preload`）。
- `theme.json`：样式与界面（见 `样式控制.md`）。

构建时编译器把本文件与引擎模板的 `info.json` **深度合并**（缺字段继承默认，`null` 视为显式置空），再把合并结果并入 `theme.info`；运行时各模块从 `window.__THEME__.info` 读取。合并语义见 `编译原理.md`。剧本指令见 `指令.md`；引擎总体设计见 `定义.md`。

## 1. 快速开始

最小可用配置：

```json
{
  "name": "Example Game",
  "version": "1.0.0",
  "autoSave": true,
  "quickSave": true,
  "preload": {
    "boot": "title",
    "runtime": ["page", "predict"],
    "predictLookahead": 20
  }
}
```

要点：

- `name` / `version` 均可省略；省略后对应位置不显示。
- `autoSave` / `quickSave` 默认 `true`，关闭会影响存档界面与首页「继续」按钮。
- `preload` 的默认值即上例，多数游戏无需修改。
- 修改 `info.json` 后必须重新构建工程（`aliceadv build <工程目录>`），否则不生效。

## 2. 顶层字段一览

| 字段 | 类型 | 必填 | 说明 | 默认值 |
|---|---|---|---|---|
| `name` | string | 否 | 游戏名，用于首页标题与关于页 | — |
| `version` | string | 否 | 游戏版本号，用于首页标题与关于页 | — |
| `autoSave` | boolean | 否 | 是否启用自动存档 | `true` |
| `quickSave` | boolean | 否 | 是否启用快速存档 | `true` |
| `preload` | object | 否 | 资源预加载策略（启动遮罩 + 运行时网络优化） | `{"boot":"title","runtime":["page","predict"],"predictLookahead":20}` |

表中「—」表示模板 `info.json` 不含该键，省略后使用模板默认值。

## 3. name / version

- `name`：显示在首页标题区（`theme.json` 的 `pages.title.showName` 不为 `false` 时）与关于页标题。
- `version`：显示在首页标题区（`pages.title.showVersion` 不为 `false` 时）与关于页「游戏版本」。

两者均可省略；省略后首页与关于页对应位置留空。

**引擎版本不在此配置。** 运行时界面展示的引擎名称与版本由构建时注入的 `window.__ENGINE__` 提供，取自引擎包的 `ENGINE_NAME` / `ENGINE_VERSION`（定义在 `aliceadv/src/aliceadv/__init__.py`，版本号的唯一来源是 `aliceadv/src/aliceadv/_version.py`），随引擎升级自动变化。工程无需也无法声明引擎版本。改引擎版本见 `编译原理.md` §5.2。

## 4. autoSave / quickSave

这两个布尔值是存档系统的总开关，由 `script.js` 的 `cfgBool("autoSave", true)` / `cfgBool("quickSave", true)` 读取（缺省视为 `true`）。

| 字段 | 默认值 | 关闭（`false`）后的影响 |
|---|---|---|
| `autoSave` | `true` | 自动存档槽从存档 / 读档页消失；首页「继续」按钮置灰且点击无效（按钮是否显示仍由 `theme.json` 的 `buttons` / `customButtons` 决定） |
| `quickSave` | `true` | 快速存档槽从存档页消失；菜单「快存 / 快读」与舞台工具栏对应按钮失效 |

关闭 `autoSave` 时，若 `theme.json` 的 `buttons` / `customButtons` 仍保留了 `continue`，首页会呈现一个置灰、点击无效按钮。建议同步移除 `continue` 以避免该状态。

## 5. preload（资源预加载策略）

`preload` 控制两件事：进入游戏时的启动遮罩行为（强制加载哪些资源后才放行玩家），以及进入游戏后的运行时资源预取。读取与执行由 `style/preload.js` 的 `AliceADVPreload` 模块完成；策略来源为 `window.__THEME__.info.preload`。

### 5.1 概述

| 子字段 | 作用 |
|---|---|
| `boot` | 启动时强制加载的素材范围；加载完成（或总超时兜底）后渐隐启动遮罩 |
| `runtime` | 进入游戏后的运行时预加载策略数组；空数组 `[]` 表示关闭 |
| `predictLookahead` | `predict` 与进舞台开场预加载的前瞻深度（向前扫描的指令条数）；默认 20，上限 200 |

`predictLookahead` 同时驱动运行时 `predict` 与进舞台开场预加载的视野范围，修改它会同时影响两者。

### 5.2 preload.boot

| 取值 | 加载范围 | 默认 |
|---|---|---|
| `"none"` | 不强制加载，遮罩立即消失 | 否 |
| `"title"` | 首页素材：`pages.title.background` 与 `customButtons` 的 `image` / `hover` | 是 |
| `"system"` | 首页 + 各启用系统页背景 + 舞台背景；`gallery` / `branches` / `chapters` 对应目录为空视为禁用，跳过其专属素材 | 否 |
| `"title+story"` | 首页 + 全部剧情素材（所有剧本的 `bg` / `show` / `music` / `sound` / `voice` 资源路径 + 角色档案全部立绘 + 角色专属对话框） | 否 |

`boot` 阶段阻塞启动遮罩，直到对应资源加载完成或触发总超时（见 5.4）。

默认值说明：`"title"` 只等待首页，启动速度快，且避免首页背景「慢慢浮出」，是多数游戏的折中值。`"system"` 与 `"title+story"` 启动更慢，分别适用于担心系统页切换空白、或愿接受较长启动以换取进入游戏后零加载延迟的场景。

### 5.3 preload.runtime

运行时预加载策略数组，可任意组合下列键；设为 `[]` 表示关闭运行时预加载。

| 键 | 行为 |
|---|---|
| `"page"` | 切换页面前，后台预加载目标页背景，不阻塞切换 |
| `"predict"` | 剧情推进时向前扫描 `predictLookahead`（默认 20）条指令，按「音效 / 音乐（最高）→ 语音 → 场景背景 → 角色立绘」串行预取；会跟随 `goto` / `if` / `decide` 控制流进入后续段，并对 `decide` 的**各**选项分支全部预载；音效最易「突变」，故优先级最高 |

默认 `["page", "predict"]` 可同时获得「页面切换平滑」与「剧情资源就绪」，且不引入可感知副作用。设为 `[]` 时，未预载的资源在实际用到时由 DOM 渲染触发惰性加载，表现为逐条出现的加载延迟。

### 5.4 启动遮罩机制

- 遮罩 DOM（`#boot-mask` 与子元素 `.boot-spinner`）写死在 `index.html`，CSS 默认 `opacity:1` 且 `pointer-events:all`，进入网页即显示纯黑背景与转圈动画。
- `AliceADVPreload.boot()` 完成后调用 `hideMask()`：为遮罩添加 `is-hidden` 类触发 0.45s 渐隐；渐隐结束后 `pointer-events` 置为 `none`，玩家方可交互。
- 单资源预加载超时 8s；启动总超时 12s。任一超时即兜底放行，避免单个坏资源无限卡住玩家。
- 模板模式且无法加载 `theme.json`（例如直接用 `file://` 打开模板）时，`bootstrap` 立即调用 `hideMask()` 并展示使用说明，遮罩无实际意义。

### 5.5 禁用功能的联动

`boot:"system"` 调用 `collectSystem` 时，会先经 `isPageEnabled` 判断功能是否启用：`gallery` / `branches` / `chapters` 对应的 `story/chapters.json` 目录数组为空视为禁用，跳过其专属素材预加载。其余系统页（`save` / `load` / `settings` / `about`）始终启用。

注意：`runtime` 的 `"page"` 策略走 `collectPageAssets`，该函数不判断 `isPageEnabled`；被禁用的系统页不会被导航到，因此不会发起其背景的预加载请求，无需额外排除。

### 5.6 进舞台开场预加载

进入舞台（点击「开始游戏」、首页「继续」、读档 / 快速读档等）时，若 `runtime` 含 `"predict"`，`script.js` 的 `start()` / `load()` 会在切换至 `page_stage` 前调用 `AliceADVPreload.enterStage(script, seg, idx)`：先显示启动遮罩（转圈圈），按 `predictLookahead` 视野预载「开场资源」——即当前段前 `predictLookahead` 条指令的资源，并跟随控制流覆盖后续段与 `decide` 各分支前 `predictLookahead` 条资源——全部就绪（或触发总超时兜底）后再隐藏遮罩、揭示舞台。

此机制用于消除开场首屏因资源未加载而出现的空白 / 闪烁：默认 `boot:"title"` 只预载首页，首屏剧情资源原本靠运行时惰性加载，开场预加载把它们提前到进舞台前完成。

- 仅在 `runtime` 含 `"predict"` 时生效；`predict` 关闭则直接进舞台（与「关闭 = 逐行惰性加载」一致）。
- 视野范围与运行时 `predict` 共用 `predictLookahead`，因此调整前瞻深度会同时影响开场预加载与运行时预加载。
- 若开场视野无可预载资源，则不弹遮罩，避免无意义闪一下。

## 6. 速查表

| 场景 | 推荐配置 |
|---|---|
| 普通游戏 | `boot:"title"`, `runtime:["page","predict"]`（默认值） |
| 极小游戏 / 本地调试 | `boot:"none"`, `runtime:[]` |
| 担心系统页切换闪烁 | `boot:"system"`, `runtime:["page","predict"]` |
| 剧情资源总量可控、追求进入游戏后零加载延迟 | `boot:"title+story"`, `runtime:["predict"]` |
