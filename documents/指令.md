# aliceADV 指令手册

本文面向编写剧本的使用者，覆盖 aliceADV 全部剧本指令的功能与用法。字段级完整规格见 `core/documents/剧本格式说明.md`，两者如有出入，以规格文档为准。

阅读约定：

- 剧本由一串指令构成，每条指令是一个 JSON 对象，`cmd` 字段指定指令名。
- 指令分两类：**阻塞**指令执行后等待玩家点击（如 `say`）；**非阻塞**指令执行后立即继续（如 `bg`）。第 4 章速查表标注了每条指令的类别。
- 资源路径相对工程根目录，如 `images/bg/classroom.png`、`audio/bgm/spring.mp3`。

## 1. 1 分钟入门

本章用三个指令搭建一个最小可运行场景：背景、角色立绘和一段对话。掌握本章内容后即可创建一个能游玩的基础剧本。

### 1.1 切换背景：`bg`

`bg` 将指定图片设为当前场景的背景。

```json
{ "cmd": "bg", "src": "images/bg/classroom.png" }
```

| 字段 | 类型 | 必填 | 说明 | 默认值 |
|---|---|---|---|---|
| `src` | string | 是 | 背景图路径 | — |
| `transition` | string | 否 | 切换效果，如 `"fade"` | 直接切换 |

`scene` 与 `bg` 行为相同，是同一指令的别名，按项目既有约定选择其一即可。

### 1.2 显示角色或图片：`show`

`show` 将角色立绘或图片添加到当前场景。

```json
{ "cmd": "show", "char": "elin", "sprite": "normal", "at": "center" }
```

| 字段 | 类型 | 必填 | 说明 | 默认值 |
|---|---|---|---|---|
| `char` | string | 与 `src` 二选一 | 角色 ID，须在 `story/characters.json` 中登记 | — |
| `sprite` | string | 否 | 立绘/表情名，取自角色档案 | — |
| `src` | string | 与 `char` 二选一 | 直接指定图片路径，无需角色档案 | — |
| `at` | string | 否 | 站位：`left` / `center` / `right` | `center` |
| `anim` | string | 否 | 入场动画类名 | `anim-fade`（淡入） |
| `transition` | string | 否 | 切换效果 | — |

移除角色或图片使用 `hide`，通过 `char` 或 `src` 指定目标：

```json
{ "cmd": "hide", "char": "elin" }
```

已在场景中的角色切换表情应使用 `sprite`（见 3.2）；重复 `show` 会重播入场效果。

### 1.3 角色对话与旁白：`say` / `narrate`

`say` 显示一句角色对话，执行后等待玩家点击。

```json
{ "cmd": "say", "char": "elin", "text": "早上好！" }
```

| 字段 | 类型 | 必填 | 说明 | 默认值 |
|---|---|---|---|---|
| `char` | string | 是 | 角色 ID | — |
| `text` | string | 是 | 对话文本，支持行内条件与句中停顿（见 2.6、3.5） | — |
| `as` | string | 否 | 临时显示名，覆盖角色名 | — |
| `sprite` | string | 否 | 说话同时切换表情 | — |
| `voice` | string | 否 | 绑定的一次性语音路径 | — |
| `voiceVolume` | number | 否 | 语音音量 | — |
| `append` | boolean | 否 | 追加续说模式（见 3.5） | `false` |
| `pause` | number | 否 | `append` 时自动续行的秒数 | 等待点击 |

旁白（无角色名）使用 `narrate`：

```json
{ "cmd": "narrate", "text": "清晨的阳光洒进教室。" }
```

### 1.4 组合成最小可运行剧本

```json
[
  { "cmd": "bg", "src": "images/bg/classroom.png" },
  { "cmd": "show", "char": "elin", "sprite": "normal", "at": "center" },
  { "cmd": "say", "char": "elin", "text": "早上好！" },
  { "cmd": "narrate", "text": "她歪着头，眼里满是期待。" }
]
```

运行这段剧本，场景会依次设置背景、显示角色并显示对话。到这里已经掌握创建最小场景所需的三个基础指令。

### 1.5 构建并运行

```bash
python3 core/build.py 你的工程目录
```

产物位于 `你的工程目录/dist/web/`，用浏览器打开其中的 `index.html` 即可游玩。构建产物支持 `file://` 协议直接打开，无需本地服务器。剧本或配置修改后需要重新构建。

## 2. 分支系统：变量、判断与段

线性剧本用第 1 章的指令已经足够。要让玩家的选择影响后续剧情，需要三个机制的组合：以段为单位组织剧情、用变量记录状态、按条件在段之间跳转。

### 2.1 段（segment）：剧情的基本单元

剧本按段组织。每段是一组指令的列表，段名在全局唯一：

```json
{
  "segments": {
    "after_school": [],
    "meet_at_tea": []
  }
}
```

上例中 `after_school`、`meet_at_tea` 是段名，其值为该段的指令列表。剧情单元以段为粒度，跳转也都以段为单位。

无条件跳转使用 `goto`：

```json
{ "cmd": "goto", "segment": "meet_at_tea" }
```

### 2.2 变量：声明与修改

变量用于记录玩家的选择、好感度等状态。初始值声明在剧本根节点：

```json
{ "vars": { "favor": 0, "went_home_together": false } }
```

修改变量使用 `set`（非阻塞）：

```json
{ "cmd": "set", "var": "favor", "op": "add", "value": 1 }
```

| `op` | 行为 |
|---|---|
| `=` | 赋值为 `value`（缺省值） |
| `add` / `sub` / `mul` / `div` | 加 / 减 / 乘 / 除 |
| `toggle` | `true` / `false` 互转，无需 `value` |
| `append` | 数组追加元素，或字符串拼接 |

写入未声明的变量时引擎会自动创建。建议在根节点集中声明全部变量：未集中声明会降低大型剧本的可维护性。

变量在游玩期全局有效。进入章节时重置为初始值，退出播放时清空；回退台词时，变量随快照一并还原到当时的状态。

### 2.3 玩家选择：`decide`

```json
{
  "cmd": "decide",
  "prompt": "放学后你打算……",
  "options": [
    { "text": "陪她一起回家", "goto": "walk_home",
      "set": { "var": "went_home_together", "op": "=", "value": true } },
    { "text": "说改天再约", "goto": "alone" }
  ]
}
```

选项字段：

| 字段 | 说明 |
|---|---|
| `text` | 选项显示文本 |
| `goto` | 选中后跳转的段 |
| `set` | 选中后执行的变量写入，接受单个对象或数组 |
| `record` | 将选择结果写入指定变量：定义了 `value` 时记 `value`，否则记选项文本 |

### 2.4 条件跳转：`if`

```json
{ "cmd": "if", "test": "favor >= 3", "goto": "good_end", "else": "normal_end" }
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `test` | 与 `var`/`op`/`value` 二选一 | 表达式字符串 |
| `var` + `op` + `value` | 与 `test` 二选一 | 结构化条件，等价于 `var op value` |
| `goto` | 否 | 条件成立时跳转的段 |
| `else` | 否 | 条件不成立时跳转的段 |

`goto` 与 `else` 均省略时，条件不成立则继续当前段，该指令无效果。

### 2.5 剧情图与汇合

分出去的剧情线可以通过跳转到同一段实现汇合：

```
            回家
           /    \
      normal线   Mozi线
           \    /
            ↓
          common
```

normal 线和 Mozi 线是两个独立的段，各自结束后都 `goto` 到 `common` 段，剧情重新合为一条线。剧情图不需要额外机制，完全由段和跳转构成。

### 2.6 汇合后的细小差异

两条线汇合后剧情大部分相同、仅个别台词不同时，不建议为此拆分新段。有两种轻量写法。

**写法一：行内条件。** 在 `text` 中插入 `{if}` 表达式，显示时按当前变量解析：

```json
{
  "cmd": "say",
  "char": "elin",
  "text": "我喜欢喝奶茶。{if went_home_together: \"昨天你送我回家，还帮我拎了那么沉的包，太够意思了！\"; else: \"下次我们一起去那家新开的店吧。\"}"
}
```

支持 `elif` 链：`{if 条件一: "文本"; elif 条件二: "文本"; else: "文本"}`。适用于"同一句话、两种说法"的场景。

**写法二：单条指令的 `if` 字段。** 任意指令可附加 `if` 字段，条件不满足时整条指令跳过，不阻塞当前段推进：

```json
[
  { "cmd": "say", "char": "elin", "text": "我喜欢喝奶茶。" },
  { "cmd": "say", "char": "elin", "text": "昨天你送我回家，还帮我拎了那么沉的包。", "if": "went_home_together" }
]
```

第一句无条件执行；第二句仅在 `went_home_together` 为真时出现。适用于"整句有或没有"的场景。

### 2.7 表达式语法

`if` 指令、单条指令的 `if` 字段与行内 `{if}` 共用同一套表达式语法：

- 变量名、数字、字符串（单引号或双引号）
- 比较：`==` `!=` `>` `<` `>=` `<=`（宽松比较，数字与字符串可互通）
- 逻辑：`&&` `||` `!`
- 算术：`+` `-` `*` `/`
- 括号分组

表达式由引擎内置的手写解析器求值，不使用 `eval`。函数调用、属性访问等写法不受支持。

### 2.8 章节组织（两层次结构）

剧情规模较大时，可在剧本根节点用 `chapters` 按章组织，每章包含自己的 `segments`：

```json
{
  "chapters": {
    "ch3": {
      "title": "第三章",
      "start": "ch3_evening",
      "segments": {
        "ch3_evening": [],
        "ch3_normal": [],
        "ch3_mozi": [],
        "ch3_common": []
      }
    }
  }
}
```

构建时各章的 `segments` 会合并为统一的段集合，段名仍需全局唯一。`start` 指定该章的入口段，未指定时使用章内第一个段。完整字段说明见 `core/documents/剧本格式说明.md`。

## 3. 其余指令

### 3.1 音频：`music` / `sound` / `voice` / `stop`

**`music`：背景音乐，默认无限循环。**

```json
{ "cmd": "music", "src": "audio/bgm/spring.mp3", "volume": 0.5, "fade": 2 }
```

| 字段 | 类型 | 说明 | 默认值 |
|---|---|---|---|
| `src` | string | 音频路径 | — |
| `volume` | number | 音量 0~1 | `0.6` |
| `loop` | 见下表 | 播放次数 | 无限循环 |
| `fade` | number | 淡入秒数 | `0`（立即） |
| `ifChanged` | boolean | 同一曲目已在播放时不重新开始 | `false` |

`loop` 取值：不写或 `true` → 无限循环；`false` 或 `0` → 播放一次；正整数 `N` → 播放 N 次后自动停止。

**`sound`：一次性音效。** 播放一次即结束，无需停止指令。默认音量 `0.85`。

```json
{ "cmd": "sound", "src": "audio/sfx/door.mp3" }
```

**`voice`：一次性语音。** 通常绑定在 `say` 上（`voice` / `voiceVolume` 字段），也可独立触发：

```json
{ "cmd": "voice", "src": "audio/voice/elin_laugh.mp3" }
```

**`stop`：停止播放。**

```json
{ "cmd": "stop", "what": "music", "fade": 1 }
```

`what` 取 `"music"` / `"sound"` / `"all"`，缺省 `"all"`；`fade` 为淡出秒数。

### 3.2 切换表情：`sprite`

`sprite` 用于已在场景中的角色切换立绘，不重播入场效果：

```json
{ "cmd": "sprite", "char": "elin", "sprite": "shy" }
```

与 `show` 的区别：`show` 用于首次出现（带入场动画），`sprite` 用于纯切换。`say` 的 `sprite` 字段可在说话同时切换表情，效果与在 `say` 前单独执行 `sprite` 相同。

### 3.3 改名：`rename`

用于"？？？"揭示真名一类的场景，更改角色在对话框中的显示名：

```json
{ "cmd": "rename", "char": "mystery", "to": "聂菲丝" }
```

### 3.4 NVL 整屏旁白：`narrate` + `nvlclear`

`narrate` 加 `mode: "nvl"` 进入整屏旁白模式，文本逐行累积：

```json
[
  { "cmd": "narrate", "text": "夜深了，城市渐渐安静下来。", "mode": "nvl" },
  { "cmd": "narrate", "text": "远处偶尔传来几声犬吠。", "mode": "nvl" },
  { "cmd": "nvlclear" }
]
```

`nvlclear` 清空累积文本。普通 `narrate` 或 `say` 会自动退出 NVL 模式，回到对话框显示。

### 3.5 文本效果：句中停顿与追加续说

**句中停顿。** 文本中插入 `{w}`，打字到此处暂停，等待玩家点击后继续；`{w=1.5}` 则暂停 1.5 秒后自动继续：

```json
{ "cmd": "say", "char": "elin", "text": "那个……{w}其实我有点事想跟你说。" }
```

**追加续说。** `say` 加 `append: true` 时不清空对话框，新文本接在已有文本后继续打出。两条 `say` 之间可以插入其他指令（换表情、换背景、音效等），用于表现"说到一半变色、再补充后半句"的演出：

```json
[
  { "cmd": "say", "char": "elin", "text": "我觉得吧……" },
  { "cmd": "sprite", "char": "elin", "sprite": "serious" },
  { "cmd": "say", "char": "elin", "text": "这事儿应该没那么简单。", "append": true }
]
```

`append` 语句默认同样等待点击；加 `pause: 1.2` 则 1.2 秒后自动进入下一句，点击可跳过。

### 3.6 演出等待：`wait`

```json
{ "cmd": "wait", "seconds": 1.2 }
```

`ms` 与 `seconds` 二选一，都未指定时默认 800ms。等待期间玩家点击可跳过。

### 3.7 章节标题与结束：`title` / `end`

```json
{ "cmd": "title", "text": "第三章 · 放学之后" }
```

```json
{ "cmd": "end", "action": "title" }
```

`end` 的 `action` 缺省为 `"title"`（返回标题页）；设为 `"chapters"` 返回章节列表。

### 3.8 存档与读档

存档由引擎自动完成，写作者无需在剧本里写任何指令；这里说明存档槽里**记录并显示什么**，以及写入后的反馈。

**存档槽显示内容**

每个存档槽由三部分组成：

- **缩略图**：保存瞬间的背景图（`bg` 当前值）。角色立绘不在缩略图内，但会随读档一并恢复。
- **文字信息**：一行「说话者 + 当前这句台词」。
  - 普通对话：显示角色名（改名后显示改名结果）与台词。
  - 旁白（`narrate`）：说话者显示为「旁白」，文字为旁白内容。
  - 选项（`decide`）：说话者显示为「选择」，文字为选项的提问语（`prompt`）。
- **保存时间**：格式为 `年/月/日 时:分:秒`（例如 `2026/09/08 14:30:05`），记录到秒。

**保存时机与反馈**

- 进入「保存」页点槽位即写入；写入成功后弹出「已保存」提示（风格与退出确认框一致，约 1.6 秒自动消失，也可点「确定」关闭）。不再使用浏览器 `alert`。
- 未开始游戏时（没有可保存的进度）点保存不会写入空槽。
- 工具栏的「快存 / 快读」使用独立的快速存档槽，与主存档槽互不影响。

**读档**

- 「读档」页只显示已有存档的槽位，空槽不可点。点已存槽位即恢复：背景、在场角色、当前台词、变量、改名、NVL 整屏、历史记录都会还原，并回到保存时那一句等待点击。
- 若保存时正停在选项界面，读档后会重建该选项界面。

## 4. 指令速查表

| 指令 | 功能 | 关键字段 | 等待点击 |
|---|---|---|---|
| `say` | 角色对话 | `char`, `text`, `as`, `sprite`, `voice`, `append`, `pause` | 是 |
| `narrate` | 旁白 | `text`, `mode: "nvl"` | 是 |
| `bg` / `scene` | 切换背景 | `src`, `transition` | 否 |
| `show` | 显示角色/图片 | `char`+`sprite` 或 `src`, `at`, `anim` | 否 |
| `hide` | 移除角色/图片 | `char` / `src` | 否 |
| `sprite` | 切换立绘表情 | `char`, `sprite` | 否 |
| `nvlclear` | 清空 NVL 整屏 | — | 否 |
| `rename` | 角色改名 | `char`, `to` | 否 |
| `decide` | 玩家选择 | `prompt`, `options: [{text, goto, record, set}]` | 是 |
| `set` | 写变量 | `var`, `op`, `value` | 否 |
| `if` | 条件跳转 | `test` 或 `var`+`op`+`value`, `goto`, `else` | 否 |
| `goto` | 跳转到段 | `segment` | 否 |
| `music` | 背景音乐 | `src`, `volume`, `loop`, `fade`, `ifChanged` | 否 |
| `sound` | 一次性音效 | `src`, `volume` | 否 |
| `voice` | 一次性语音 | `src`, `volume` | 否 |
| `stop` | 停止播放 | `what`, `fade` | 否 |
| `wait` | 演出等待 | `seconds` / `ms` | 是（可跳过） |
| `title` | 章节标题卡 | `text` | 是 |
| `end` | 章节结束 | `action` | 是 |

任意指令均可附加 `if: "<表达式>"` 字段：条件不满足时整条指令跳过，不阻塞当前段推进。在汇合段写细小差异时常用（见 2.6）。

## 5. 构建与维护

引擎已封装为 `aliceadv` Python 包，安装后通过命令行构建工程：

```bash
pip install -e .          # 在 aliceadv/ 目录下安装引擎包
aliceadv create 你的工程目录 --name "游戏名"
aliceadv build  你的工程目录
```

- 产物位于 `你的工程目录/dist/web/`，浏览器打开 `index.html` 即可游玩，`file://` 协议下可直接运行。
- 剧本、主题或配置修改后需要重新构建，否则改动不会生效。
- 指令集发生变更时，本手册与 `core/documents/剧本格式说明.md` 会同步更新。
